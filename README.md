# Showbiz Abuja

Events across Abuja, free ones first, with Transcorp Hilton and Abuja Continental highlighted.

Live at: https://showbiz.elnonso.com

## Files
- index.html: the website (bright light and dark themes)
- events.json: the event list. Edit this file on GitHub to update the site.
- CNAME: tells GitHub Pages to use showbiz.elnonso.com
- manifest.webmanifest, icon.svg: let phones install it with "Add to Home screen"

## Adding an event
Copy any entry in events.json and change the fields. venueKey is transcorp, continental or other. category is one of Business, Tech, Expo, Conference, Health, Faith, Community, Entertainment, Training, Fashion. Dates use YYYY-MM-DD.
